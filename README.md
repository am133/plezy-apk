# plezy-apk

Auto-mirrors the official [Plezy](https://github.com/edde746/plezy) Android APK (armeabi-v7a) as plain `.apk` release assets, so it can be tracked by [Obtainium](https://github.com/ImranR98/Obtainium) on Fire TV.

The APK is the unmodified upstream build (original signature), extracted from the upstream `.tar.gz` release asset. A scheduled workflow checks for new releases every 6 hours.
